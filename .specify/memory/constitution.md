# VoiceSpeed 项目宪法

## 核心原则


### I. 用户体验优先

交互必须响应迅速，错误状态必须显示清晰的中文提示。

## 开发工作流

- 源代码位于 `src/app/` 目录，遵循 Next.js App Router 规范。
- 导入使用路径别名（`@components`、`@services`、`@utils`、`@config`、`@interfaces`）。
- 功能规范文档位于 `specs/` 目录，遵循 SpecKit 规范。

## 治理规则

本宪法优先于项目的所有其他开发实践。
任何修订必须记录版本变更和修改理由。
