# Quickstart: VoiceSpeed 实时语速监测

## 环境准备

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`

## 验证场景

### 场景 1：正常语速监测

1. 点击"开始录音"
2. 对着麦克风说一段话（约 10 秒）
3. 观察语速数值和等级是否实时更新
4. 点击"停止"，确认最终数值保留

**预期结果**: 语速数值在 2 秒内出现，等级正确显示

### 场景 2：麦克风未授权

1. 在浏览器设置中禁用麦克风权限
2. 点击"开始录音"

**预期结果**: 显示中文提示引导用户授权

### 场景 3：语速等级验证

- 慢速说话（每分钟约 100 字）→ 应显示"偏慢"
- 正常说话（每分钟约 150 字）→ 应显示"适中"
- 快速说话（每分钟约 200 字）→ 应显示"较快"
